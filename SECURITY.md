# Security policy

This public repository is a documentation-only architecture case study. Current
cluster configuration, hostnames, secrets, Argo CD applications, Helm values,
and live deployment manifests are maintained outside this repository.

If you discover a credential, private key, access token, or current sensitive
endpoint in the repository or its historical commits, do not open a public
issue. Report it privately through GitHub's security-advisory interface for this
repository.

Architecture details and archival environment configuration that do not grant
access are not treated as active operational support commitments.
